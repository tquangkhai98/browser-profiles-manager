# v0.2.0 draft release notes

## What's new

- Linux amd64 and arm64 CLI builds include the MCP server and work without a GUI.
- Headless Chromium launch supports automatic display detection, explicit configuration, and a reported CDP endpoint.
- Linux browser detection covers more installation locations and PATH.
- `bpm launch` and `bpm stop` manage detached browsers; launch JSON includes CDP HTTP and WebSocket endpoints.
- Export profiles to tar.gz, tgz, or zip archives and import archives or copied Chrome profile directories.
- Linux launches use `--password-store=basic` to avoid tying newly stored cookies to a host keyring.
- Browser-owned profile locks prevent simultaneous use and block export while running unless forced; stale locks are cleaned up.

## Breaking changes

None expected for CLI users. Building the desktop Go package now requires `-tags desktop` (or `make desktop`).

## Upgrade

Replace the CLI binary with the appropriate release artifact. Install Chromium or Chrome for browser launches. Linux desktop builds need GTK 3 and WebKitGTK 4.0.

## Verification

Compare the SHA-256 digest of the downloaded artifact with the published `checksums.txt`, for example `sha256sum -c checksums.txt` after downloading the artifacts.

Verification depends on the release build and its published checksums.
